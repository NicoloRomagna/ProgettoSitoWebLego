# REPORT FINALE – SitoWebLego
## Obiettivo
Ho realizzato un sito web dedicato ai LEGO.
L’idea è permettere agli utenti di:
- Vedere i set LEGO
- Cercare singoli mattoncini
- Leggere informazioni sulla storia LEGO
- Osservare le varie creazioni

### Funzionalità
#### Autenticazione:
- Registrazione
- Accesso (Login)
- Logout

### Gestione Set LEGO
- Aggiunta nuovi set
- Eliminazione set
- Modifica set

### Catalogo Mattoncini
- Lista di mattoncini
- divisione per colori
- Ricerca dei singoli pezzi

### Contenuti Extra
#### Storia LEGO:
- Immagini dell'evoluzione dei prodotti
- Racconto delle origini dell'azienda Lego
### Creazioni:
- Immagini di creazioni Lego

### Tecnologie usate:
- Python 
- Flask
- HTML + CSS
- SQLite

#### Installazione e Avvio
##### 1. Clonare il repository e aprirlo in VSCode:
- git clone https://github.com/NicoloRomagna/ProgettoSitoWebLego.git
##### 2. Installare le dipendenze:
- pip install flask, flask_login e flask_sqlalchemy
- pip install -r requirements.txt
##### 3. Avviare l’applicazione:
- python setup_db.py (crea database --> instance)
- python run.py
##### 4. Aprire il browser e andare su:
http://127.0.0.1:5000/

###### 5. Io non ho fatto il deploy.
